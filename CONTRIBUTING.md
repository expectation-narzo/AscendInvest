# Contributing to Ascend Invest

First off, thank you for considering contributing to Ascend Invest! It's people like you that make the fintech community such a great place.

## How Can I Contribute?

### Reporting Bugs
*   Ensure the bug was not already reported by searching on GitHub under [Issues](https://github.com/expectation-narzo/AscendInvest/issues).
*   If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/expectation-narzo/AscendInvest/issues/new).

### Suggesting Enhancements
*   Open a new issue and describe the feature you would like to see, why it would be useful, and how it should work.

### Pull Requests
1.  Fork the repo and create your branch from `main`.
2.  If you've added code that should be tested, add tests.
3.  If you've changed APIs, update the documentation.
4.  Ensure the test suite passes.
5.  Make sure your code lints.

## Style Guide
*   **Android:** Follow Google's Java Style Guide.
*   **Web:** Use TypeScript and follow the existing ESLint configuration.
*   **Commits:** Use conventional commits (e.g., `feat:`, `fix:`, `docs:`, `chore:`).
