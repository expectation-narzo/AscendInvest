# Security Policy

## Supported Versions

We are currently supporting the following versions of Ascend Invest:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Ascend Invest seriously. If you find any security vulnerabilities, please do not report them via public issues.

Instead, please send an email to the lead developer via the contact information provided in the [README.md](README.md).

We will acknowledge your report within 48 hours and provide a timeline for a fix if necessary.
